# 峡谷宝石战（消消乐对战）

一款模仿《战神的挑战》（Gems of War / Puzzle Quest）三消对战玩法的网页游戏，英雄与技能取材于《王者荣耀》。

> 粉丝自制 Demo，与腾讯《王者荣耀》及 Infinite Interactive《Gems of War》无关，仅作学习交流。

## 如何运行

- **方式一**：直接双击 `index.html` 用浏览器打开即可（无任何依赖、无构建步骤）。
- **方式二**（推荐体验）：本地起服务后访问
  ```
  python -m http.server 8377
  # 浏览器打开 http://127.0.0.1:8377/
  ```

## 游戏模式

- **单挑对决**：与选定的对手 1v1。
- **征服模式**：选 1 名英雄连闯 **5 关**（兰陵王 → 白起 → 钟馗 → 镜像对决 → 暗影主宰），生命/护甲/攻击/法力**全程延续**；每消 1 颗黄金宝石 +1 金币，通关另奖励金币；关卡之间进入**征服商店**，随机 4 件商品任选购买（治疗/护甲/攻击/法力/生命上限）；阵亡或投降则征服结束，结算显示止步关卡。

## 玩法规则（仿《战神的挑战》）

1. **8×8 棋盘**，6 种宝石：烈焰🔥、寒霜💧、灵藤🍃、黄金👑、暗能🔮、骷髅💀。
2. 点击两枚相邻宝石交换，凑成 **3 消** 以上即消除并下落补位（支持连锁）。
3. **同色宝石**消除后为你方英雄充能（仅充其亲和色，单色上限 16）。
4. **骷髅匹配**直接攻击敌方英雄：每颗骷髅伤害 = 你方英雄的**攻击力**；4 连骷髅 ×2、5 连以上 ×3；伤害先扣护甲再扣生命。
5. **4 消**获得一个**额外回合**（连锁中的 4 消也算）。
6. **5 消**额外生成一枚**末日骷髅**（结算时按 2 颗骷髅计，无法被技能转化/摧毁）。
7. 轮到你了，可以选择**走一步棋**或**施放一个技能**（施放消耗本次行动）。法力足够时技能栏会发绿光，每个技能下方直接显示效果说明；未充能时还会提示还差哪些颜色的法力。
8. 1v1 单挑：击败敌方英雄即获胜；你的英雄倒下则战败。

## 英雄与属性设计

每名英雄 4 项基础属性 + 2 种法力亲和色 + 3 个技能：

| 属性 | 作用 |
|---|---|
| ❤ 生命 HP | 归零阵亡（1v1 下即战败） |
| 🛡 护甲 | 优先吸收骷髅与技能伤害（真实伤害除外），部分技能可叠加 |
| ⚔ 攻击 | 决定每颗骷髅的伤害，部分技能可永久提升 |
| 法力亲和色 | 只有这两种宝石的消除会给英雄充能 |

### 对手（1v1 单挑，5 选 1）

- **单挑 · 白起**：64 血 20 甲坦克，吸血 + 烧蓝 + 群伤，正面消耗战。
- **单挑 · 兰陵王**：46 血 8 甲高攻刺客，可加攻击力，速战速决。
- **单挑 · 钟馗**：50 血 12 甲法师，吸蓝吸血 + 宝石转化，消耗流。
- **镜像试炼**：随机 1 名英雄的镜像对决。
- **主宰巢穴**：暗影主宰（BOSS，160 血 32 甲，五色亲和充能极快，大招「湮灭之光」44 点真实伤害；**血量过半进入狂暴**：攻击 +3，此后每 3 回合将 2 颗宝石侵蚀为骷髅）。

## 敌方 AI

支持三档难度（选人界面选择）：

- **简单**：从全部合法步中随机走子，仅在技能评分很高（基本=可击杀）时才施法；
- **普通**：每回合评估两种决策并择优（带少量随机性，前三优的走子加权随机）；
- **困难**：永远走最优步、施法阈值更低（更果断），评分噪声更小。

决策评估方式：

- **施法评分**：按技能类型估算伤害/击杀/治疗/护甲/偷蓝的价值，可击杀时大幅加分；
- **走子评分**：对全棋盘 112 种相邻交换做**完整连锁模拟**，综合骷髅伤害、有效法力充能、额外回合、末日骷髅与连锁深度打分。

## 音效与特效

- 音效全部由 WebAudio 实时合成（无外部素材）：消除音随连锁升高音调、骷髅打击噪声、施法滑音、额外回合双音、胜负旋律；战斗界面右上角可一键静音（持久化到 localStorage）。
- 特效：骷髅命中时棋盘红光震动、施法时全盘闪亮、5 消生成末日骷髅时金色粒子迸发、Boss 狂暴后头像红光燃烧。

## 项目结构

```
index.html        入口页面（五个界面：标题 / 选人 / 战斗 / 征服商店 / 结算）
css/style.css     全部样式（宝石、面板、技能、动画、特效、商店）
js/data.js        宝石 / 英雄 / 技能 / 对手 数据定义
js/audio.js       WebAudio 合成音效（可静音，持久化）
js/board.js       棋盘纯逻辑（生成、匹配合并、下落、洗牌、AI 用模拟结算）
js/skills.js      全部技能效果实现（FX 表）
js/battle.js      战斗流程（回合、消解、伤害、法力、胜负、Boss 狂暴、金币产出）
js/conquest.js    征服模式（关卡表、金币、商店、状态延续）
js/ai.js          敌方 AI（三档难度决策评估）
js/ui.js          界面渲染与交互（含动画节奏、棋盘特效）
js/main.js        应用入口、选人与模式逻辑
test/smoke.js     棋盘逻辑冒烟测试
```

## 已知设计取舍

- 施放技能 = 消耗一次行动（与 Gems of War 一致）；技能引发的棋盘变化会继续连锁结算。
- 法力上限 16（BOSS 22），法力偷取会转入施法者自己的亲和色。
- 棋盘无可行步时自动洗牌。
- `Battle.speed` 为动画速度系数（测试用），默认 1。
