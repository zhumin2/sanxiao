# 峡谷宝石战（消消乐对战）

一款模仿《战神的挑战》（Gems of War / Puzzle Quest）三消对战玩法的网页游戏，英雄与技能取材于《王者荣耀》。

> 粉丝自制 Demo，与腾讯《王者荣耀》及 Infinite Interactive《Gems of War》无关，仅作学习交流。

## 如何运行

- **方式一**：直接双击 `index.html` 用浏览器打开即可（无任何依赖、无构建步骤）。
- **方式二**（推荐体验）：本地起服务后访问
  ```
  python -m http.server 8377
  # 浏览器打开 http://127.0.0.1:8377/
  ```

## 玩法规则（仿《战神的挑战》）

1. **8×8 棋盘**，6 种宝石：烈焰🔥、寒霜💧、灵藤🍃、黄金👑、暗能🔮、骷髅💀。
2. 点击两枚相邻宝石交换，凑成 **3 消** 以上即消除并下落补位（支持连锁）。
3. **同色宝石**消除后充能给本方对应亲和色的英雄（法力优先充给站位靠前的英雄，单色上限 16）。
4. **骷髅匹配**直接攻击敌方前排英雄：每颗骷髅伤害 = 前排英雄的**攻击力**；4 连骷髅 ×2、5 连以上 ×3；伤害先扣护甲再扣生命。
5. **4 消**获得一个**额外回合**（连锁中的 4 消也算）。
6. **5 消**额外生成一枚**末日骷髅**（结算时按 2 颗骷髅计，无法被技能转化/摧毁）。
7. 轮到你了，可以选择**走一步棋**或**施放一个技能**（施放消耗本次行动）。法力足够时技能栏会发绿光。
8. 击败敌方全部英雄获胜；我方全灭则战败。

## 英雄与属性设计

每名英雄 4 项基础属性 + 2 种法力亲和色 + 3 个技能：

| 属性 | 作用 |
|---|---|
| ❤ 生命 HP | 归零阵亡 |
| 🛡 护甲 | 优先吸收骷髅与技能伤害（真实伤害除外），部分技能可叠加 |
| ⚔ 攻击 | 决定前排时每颗骷髅的伤害，部分技能可永久提升 |
| 法力亲和色 | 只有这两种宝石的消除会给该英雄充能 |

### 敌方阵容

- **峡谷反派**：白起（吸血/烧蓝/全体伤害）、兰陵王（刺客连招）、钟馗（吸蓝/吸血）、东皇太一（偷蓝/转化暗能）。
- **镜像试炼**：随机 4 名英雄组成的镜像队。
- **主宰巢穴**：暗影主宰（BOSS，300 血 50 甲，五色亲和，大招「湮灭之光」44 点真实伤害）。

## 敌方 AI

每回合评估两种决策并择优（带少量随机性，前三优的走子加权随机）：

- **施法评分**：按技能类型估算伤害/击杀/治疗/护甲/偷蓝的价值，可击杀时大幅加分；
- **走子评分**：对全棋盘 112 种相邻交换做**完整连锁模拟**，综合骷髅伤害、有效法力充能、额外回合、末日骷髅与连锁深度打分。

## 项目结构

```
index.html        入口页面（四个界面：标题 / 选人 / 战斗 / 结算）
css/style.css     全部样式（宝石、面板、技能、动画）
js/data.js        宝石 / 英雄 / 技能 / 敌方队伍 数据定义
js/board.js       棋盘纯逻辑（生成、匹配合并、下落、洗牌、AI 用模拟结算）
js/skills.js      全部技能效果实现（FX 表）
js/battle.js      战斗流程（回合、消解、伤害、法力、胜负）
js/ai.js          敌方 AI（决策评估）
js/ui.js          界面渲染与交互（含动画节奏 sleep）
js/main.js        应用入口与选人逻辑
test/smoke.js     棋盘逻辑冒烟测试
```

## 已知设计取舍

- 施放技能 = 消耗一次行动（与 Gems of War 一致）；技能引发的棋盘变化会继续连锁结算。
- 法力上限 16（BOSS 22），法力偷取会转入施法者自己的亲和色。
- 棋盘无可行步时自动洗牌。
- `Battle.speed` 为动画速度系数（测试用），默认 1。
